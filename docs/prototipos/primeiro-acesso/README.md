# Protótipo de primeiro acesso do Applyer

Na raiz do repositório, gere o HTML com Node.js.

```sh
node docs/prototipos/primeiro-acesso/build.cjs
```

Abra `docs/prototipos/primeiro-acesso/Applyer-primeiro-acesso.html` no navegador. O arquivo funciona offline. Para gravá-lo em outro local, passe o caminho de saída como argumento.

Escolha **Usar perfil de exemplo** para percorrer as etapas e revisar a triagem com o currículo e as vagas fictícias. O build incorpora as ilustrações do app e gera o PDF de exemplo.
