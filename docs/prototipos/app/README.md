# Protótipo navegável do Applyer

Na raiz do repositório, execute com Node.js:

```sh
node docs/prototipos/app/build.cjs
```

Abra `docs/prototipos/app/Applyer-prototipo-navegavel.html` no navegador. Para escolher outro arquivo de saída, passe o caminho como argumento. O HTML inclui as imagens, os estilos e os scripts e funciona offline.

O protótipo usa um perfil e vagas fictícios para simular a busca e a organização das candidaturas. As mudanças ficam no navegador.

As ilustrações e a marca Applyer são do projeto. O logotipo da Hugging Face vem do [kit de marca da empresa](https://huggingface.co/brand). As origens dos símbolos de ChatGPT, Claude, Grok e Gemini estão nos respectivos SVGs. A pasta `arte/` preserva as versões de Claude, Gemini e do ícone Applyer usadas nesta demonstração.
